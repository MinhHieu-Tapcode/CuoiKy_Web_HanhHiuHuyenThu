# Fleur Bridal – Website Cho Thuê Váy Cưới

Website giới thiệu và cho thuê váy cưới xây dựng bằng HTML/CSS/JavaScript thuần, hiển thị bộ sưu tập, sản phẩm và tin tức của tiệm áo cưới Fleur Bridal.

## Công nghệ sử dụng

* HTML
* CSS
* JavaScript (thuần)

## Tính năng chính

* Trang chủ giới thiệu thương hiệu (`Trangchu.html`)
* Bộ sưu tập váy cưới (`bosuutap`)
* Danh mục và chi tiết sản phẩm (`sanpham`)
* Trang tin tức (`tintuc`)
* Header/Footer dùng chung cho toàn bộ trang (`header_footer`)
* Giao diện responsive, tối ưu hình ảnh và tài nguyên tĩnh (`asset`)

## Nhóm thực hiện

* Môn học: Thiết kế Web | Năm: 2026

## Hướng dẫn chạy

1. Clone repo về máy
2. Mở trực tiếp file `Trangchu.html` bằng trình duyệt, hoặc
3. Dùng extension **Live Server** (VS Code) để chạy với hot reload
